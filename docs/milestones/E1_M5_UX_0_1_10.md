# E1.M5 direct sketch references - 0.1.10

Owner clarification: use existing model geometry and canonical references directly in sketch dimensions/relations, without first invoking a projection operation. This release includes the [0.1.9 sketch/navigation changes](E1_M5_UX_0_1_9.md) and implements that direct path. It does not advance E2 or imply owner acceptance.

## Behavior and persistence

- In Select mode, click a proven model vertex/edge using the appropriate View selection filter, or select Origin/an intersecting reference from Manager. Shift adds a reference to the current sketch selection. Smart Dimension and the Inspector relation choices consume these same references.
- Selection is local and read-only: no document revision, sketch primitive, history entry or operation is created. The model feature is not selected in parallel with the sketch selection.
- The actual dimension/relation command includes only the references it uses. Source identity, independently verified projection and source anchors are persisted atomically with the relation in one Undo action. Internal reference data is excluded from the sketch primitive tree and user constraint/dimension tables; it cannot be dragged or edited as local geometry.
- Source-only dimensions are measured; dimensions between local geometry and a source reference may drive the local geometry. Removing the last user relation to an implicit reference removes its unused internal data and dependency. Undo/Redo retains atomic behavior. Previous immutable versions remain intact.
- The explicit External reference tool remains an optional construction/projection tool. It is unnecessary for direct association.
- The header version comes from the packaged product manifest.

The same exact-source boundaries as 0.1.9 apply: primary part only; proven vertices, straight edges and complete circular projections; canonical datum traces/intersections. A parallel plane/face is not silently treated as a point. Arbitrary arcs, elliptical projections, curved faces and assembly occurrence editing are not claimed. Source changes that invalidate the exact witness fail with LostReference and require explicit repair; this is not general persistent topological naming. Older strict readers refuse the new reference metadata.

## Owner test

1. Install/activate 0.1.10 and load **E1.M5 Extrusion & Sketch Workbench**. Create/edit a sketch on Front or a supported planar face. Draw a free point or line.
2. In Select mode, select a local endpoint, then Shift-click Origin in Manager. The Inspector offers relations and the sketch primitive tree gains no reference primitive. Add Horizontal or Vertical: local geometry aligns with Origin. One Undo removes the relation and association; one Redo restores both.
3. In View choose the Vertex filter. Start Smart Dimension, select a local sketch point, then a distinct visible vertex of the solid. Place/confirm the dimension and edit its single Inspector Value cell. No External reference operation is necessary. Repeat with the Edge filter for supported straight edges.
4. Select/delete the created relation. Its unused implicit reference disappears. Save, close and reopen; retained dimensions/relations must keep their exact source association. Existing source geometry and immutable versions remain intact.
5. Repeat the camera, Shift-chain, dimension editor and green extrusion preview checks in the 0.1.9 guide. Enter updates extrusion preview; Apply commits it.
