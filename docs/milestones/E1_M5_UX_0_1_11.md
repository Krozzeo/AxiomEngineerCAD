# E1.M5 preview, sketch motion and selection - 0.1.11

Owner-requested refinement of E1.M5. This does not advance E2 or imply owner acceptance. The previous immutable 0.1.10 installation remains available.

## Changes and observable results

- Operation preview is a generic collection of display-only geometry layers, separate from the original model and from the candidate's verified result metrics. Extrusion contributes its exact unfused tool volume. Existing material stays gray; preview faces are translucent olive/yellow with yellow edges. Enter/blur updates Depth; Apply commits, Escape/right-click cancels. Preview layers have no native selection IDs and cannot be exported or saved as source. Future operations provide their own exact layer producer.
- Origin has priority in ordinary mouse selection, including over sketch points and solid vertices. During sketch editing, local sketch geometry otherwise takes priority over external geometry. External geometry and circle centers support preselection. Explicit Select another choices can override the ordinary priority.
- Implicit source references never appear as projected sketch primitives, either during editing or in the displayed sketch outside editing. Their internal radius anchors also produce no dimension labels. The actual source geometry supplies highlight feedback. Existing explicit construction references from earlier builds remain preserved in the document but are not advertised as ordinary converted geometry.
- Convert Entities replaces External reference. It stays highlighted while its Inspector collects a reviewable selection table. Individual removal, Clear all, Cancel and explicit Apply are available. Selection itself is read-only. One command/Undo action creates the reviewed batch as normal geometry with On edge projection relations. Removing a projection anchor detaches that entity's source association and remaining internal anchors, leaving ordinary editable geometry. Proven planar face boundaries expand to their supported exact edges, including circular holes.
- Circular model boundaries composed of several exact B-Rep arcs are recognized only after checking common circle geometry, endpoint connectivity, full circumference and one consistent winding. Partial or repeated arcs cannot masquerade as a complete circle. Native source verification independently regenerates these witnesses. Circle centers are selectable references; arbitrary arcs and elliptical projections remain outside the current sketch profile.
- Rectangle drag was affected by multiple general gesture defects: a temporary opposite-end hold reduced motion in connected constraint networks, Snap could chase coincident aliases or other moving preview points, and an off-center segment/circle grip could jump its reference point to the cursor. The hold now preserves accessible motion in connected networks, while isolated segments retain opposite-end behavior. Snap excludes equivalent/moving targets; pointer offsets and the final pointer-up goal are preserved. Actual constraints still govern movement.
- Dimension Inspector follows the supplied layout: title, Relation, Value heading/actions, one full-width numeric-or-parameter field, Reference checkbox, Targets heading/actions and target list. No second editor, unit widget, source-navigation button or unrelated relation list is shown for a dimension. Numeric focus does not open an irrelevant completion menu; parameter text opens a narrow suggestion list. Diameter labels use `Ø` immediately followed by the value.
- Parameter Manager keeps its table grid. Equation bindings and Geometric constraints search inputs have no nested input border and remain editable.
- Active proof jobs are presented promptly rather than waiting for the idle 350 ms poll. Sketch command/rebuild polling is also shorter, with revision, cancellation, numerical validation and presentation-epoch guards preserved. An eight-line physical Chrome/NVIDIA comparison reduced the approximately 344 ms placement median to approximately 180 ms; this is a measured small-fixture result, not a guarantee for all sketches.
- Model right-click offers Select another in normal and sketch views, including Convert Entities. Its table lists overlapping sketch geometry, model entities, circle centers and visible references with readable labels. Hover highlights entries; selection goes through native semantic resolution. Explicit model body/feature inspection clears the sketch selection instead of showing two competing Inspector targets.

## Owner test flow

Install/activate 0.1.11 in Platform and load **E1.M5 Extrusion & Sketch Workbench**. Preserve prior user projects.

1. Create a sketch on Front. Draw an unconstrained rectangle away from Origin and drag all four corners diagonally. Draw a separate line and drag it from a point away from its midpoint. Repeat by dragging a circle from its circumference. No direction should be artificially blocked and the grip should not jump.
2. Place a local point over Origin. An ordinary mouse selection must choose Origin. Right-click there and use Select another to choose the overlapping local point or actual solid vertex explicitly.
3. Select a free sketch point and the center of the plate hole with Smart Dimension. Check preselection, source feedback, the one-field Inspector, constant edits and parameter search. Internal source curves and radius dimensions must not appear as extra sketch geometry or labels. Save/close/reopen and exit editing to verify this.
4. Start Convert Entities. Collect several external references, remove one, clear all, and collect again. Nothing commits before Apply. Convert a visible planar face to test its complete supported boundary, or use the Edge filter for a circle. Check normal geometry and projection relations, one Undo/Redo and detachment when removing an On edge relation.
5. Create a sketch on the existing top face and preview an extrusion. Orbit to isometric: only the extrusion volume should be translucent yellow; the plate stays gray. Enter changes the preview without applying. Cancel, reopen, then Apply explicitly.
6. Inspect Parameter Manager's restored grid and borderless search cells. Use Select another both inside and outside sketch editing, hover rows and choose a specific overlapped entity.

## Scope and evidence

Primary-part editing, supported exact faces, points, straight edges and complete circular projections remain the scope. Assembly occurrence editing, arbitrary arc/spline conversion and general persistent topological naming are not claimed. Changed geometric witnesses require explicit repair. Previous native versions are preserved; strict older readers reject unsupported new conversion metadata.

Focused tests cover all corner representations, isolated and constrained movement, Snap aliases, exact operation layers, circular-boundary positives/negatives, conversion atomicity/detachment and invisible implicit references. Physical UI tests cover actual picking, motion, Inspector layout, conversion review and overlap choices. The prior public-QA attached-SVG precondition is promoted into the repository's historical hover test.

Before delivery, require complete exact-head Windows/Linux domain/browser/independent-PDF acceptance, immutable experimental ZIP/manifest publication, and actual public Platform install/activate/launch with physical GPU and Save/Close/Reopen checks. Final immutable evidence belongs in PR18 and delivery artifacts, without changing the frozen source to reference itself. Owner acceptance remains separate.
