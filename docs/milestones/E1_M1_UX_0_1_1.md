# E1.M1 UX revision — 0.1.1

Owner requested compact SolidWorks-like CAD composition and Game Engine docking after reviewing0.1.0. This corrects the same milestone. E1.M2 sketch editing has not started.

Implemented: one-line logo/menus including Panels; compact SVG-icon tools; gray solid/viewport; left History/right Inspector/bottom Activity/central Model, optional Drawing/Diagnostics; all five dock targets, tab drag/reorder, position selector, resizing, close/reopen/reset, Separate window and return-on-close using the Game Engine implementation pattern. Persistent layout is separate from the native document. No outer-page scroll at1650x1050,1280x720 and800x600. Horizontal orbit is inverted; wheel uses actual cursor surface/plane anchor for orthographic and perspective.

## Try the delivery

1. In Platform0.1.12+, Installations → Add installation → Axiom Engineer CAD → Refresh. Install/activate experimental **0.1.1**, then Load Demos → **E1.M1 Model Workbench**.
2. Drag the middle mouse button right and left; check the corrected horizontal direction. Put the pointer on a corner or face away from the screen center and turn the wheel in both directions. Repeat in Perspective. F fits the model.
3. Drag History/Inspector tabs between zones or use their Left/Right/Top/Bottom/Center selector. Drag zone borders to resize. Close a tab using X, reopen it from **Panels**. Reset panel layout restores defaults.
4. Choose **Separate window** (outward-arrow icon, or tab context menu) on Inspector. Select an entity there; its exact selection and source update the main model. Return to editor, or close the child window: the panel returns. Try separating Model while opening Drawing in the main editor. Allow browser popups for this local editor if blocked.
5. Move/close panels and reload/reopen: the arrangement returns, without opening popups automatically. Resize the browser; only panel contents scroll. The top menus stay accessible even with every panel closed.
6. Existing document properties, saving, proposals, exact drawing and earlier labs remain available. Camera/layout changes alone leave CAD revisions and saved geometry intact.
