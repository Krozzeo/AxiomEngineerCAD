# E1.M1 interaction revision — 0.1.2

Owner-requested revision of0.1.1; E1.M2 sketch editing remains unstarted. [ADR018](../architecture/ADR-018-INTERACTION-WORKBENCH.md) records scope, stable reference behavior and acceptance.

## Try it in Platform

1. Refresh installations, install/activate experimental0.1.2 and Load Demos. Only **E1.M1 Model Workbench** is offered by this release. Existing earlier projects remain in your project list; this does not delete them.
2. View tab → Selection defaults to **Auto**. Move across a corner, edge and face. Orange marks the candidate; click selects in blue. Vertex precedes Edge, which precedes Face; explicit filters remain. Edges thicken and vertices use filled circular markers.
3. Hover Front/Top/Right, axes and supported feature rows in Manager. Only the corresponding references/edges highlight. Select a reference without turning on Reference planes & axes. Origin selects the fixed definition reference point. Manager's status remains pinned below its source tabs.
4. Click a triad axis and repeat to reverse it. View buttons/Normal to and keyboard orientation animate. F8 or a double click with the middle mouse button aligns to a selected planar normal, or the nearest principal direction with no planar selection.
5. Open one top menu, then another; only one stays open. Click empty model space to dismiss. File → Document properties opens the central settings panel; Panels can reopen it. General edits Name/Notes with the same Apply/Save guards; Revisions displays current/saved revision. Inspector keeps only selection data and collapsed Details.
6. Edit Notes: quick-save and File → Save show an asterisk/highlight until changes are reset or applied/saved. Pending fields still require Apply before Save. All operation categories have tabs; future editing tabs clearly state their current availability.
7. Separate/reposition/close/reopen the panels as before. The bottom Model strip reports actual status/errors. Camera, hover and layout alone preserve CAD document bytes/revision.

Verification includes125 tests, real GPU Auto/hover and no-write probes, full retained regressions, four browser sizes through4K, separate/embedded windows and installable delivery. Final exact-head CI and fresh public Platform download/install/launch are required before publication is reported complete. The original0.1.1 release stays immutable.
