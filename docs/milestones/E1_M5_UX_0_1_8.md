## Owner verification

Install/activate 0.1.8 in Platform, then Load Demos → **E1.M5 Extrusion & Sketch Workbench**. Existing user studies stay intact.

1. Select a reference plane and New Sketch. Pick/clear supports in Manager/Model; inspect Normal/Right arrows, Reverse normal and 0/90/180/270 buttons. Escape cancels. Right-click a planar Model face or Manager plane: New Sketch is first. Try a side face, not only Front/Top/Right. A curved cylindrical face must not offer this action.
2. Draw a line/circle/rectangle: after the first click, move the mouse to see a live draft. Stored source changes only on the final click. Start another line at the prior endpoint; Snap creates a persistent coincidence. Drag a point onto an endpoint/midpoint/center/origin; Ctrl temporarily bypasses Snap. A circle radius point on a reference point creates point-on-circle. Undo reverses geometry and Snap together.
3. Select geometry: its associated relations are listed. Delete geometry and verify its relations are gone. Missing legacy refs stay listed green with Missing reference, removable or repairable; conflicts appear red. These negatives are explicit test fixtures, not broken production demos.
4. Place dimensions in either initial direction: positive follows the chosen side, negative reverses it. Keep an additional equal driving dimension: both driver owners must conflict; the label stays where Model was clicked before the modal opened. Delete/convert the redundant dimension to repair. Reference dimensions are measurements, not drivers.
5. Open Parameter Manager: Parameters, Equation bindings, Model dimensions and Geometric constraints. Create/edit/delete geometric relations with named semantic targets. Focus selects one row; leaving/blank click validates and deselects on success. Errors preserve the draft; Escape discards/deselects. Footer shows red X errors or green check success. Search is bordered; unset binding inputs are blank and filter while typing.
6. Select a sketch dimension. Value accepts a number or searched parameter. Choosing a parameter immediately binds; Model shows `ParameterName:⌀value` for a diameter. Go to source is icon-only and selects its PM row. Enter a number to replace a binding atomically; verify Undo/Redo. Incompatible units/duplicate drivers must not change the document.
7. Disabled Manager operations are opaque gray and use Enable/Disable icons distinct from Hide/Reveal. Ribbon offers New or Edit; editing shows pressed Exit Sketch. Exit selects the finished sketch. Save, close and reopen; source IDs, relations, bindings and face orientation must survive.

## Technical bounds
