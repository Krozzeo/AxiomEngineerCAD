# E0.M4 — Native graph, versions and recovery

Owner authorized continuation after the delivered E0.M3. Baseline 175b3fc8c47c456bc324d2a9778738931d4fe9b4; Platform 0.1.12 stays pinned. CAD-R005–008 and storage/reference portions of CAD-R022/023.

Implement a bounded version-1 native JSON envelope, retaining the historical project basename for Platform registration compatibility. Separate working graph, immutable content-hashed versions, publication records, recovery journal and durable save receipts. Typed stable IDs cover definitions, features/parameters, instances/occurrences, drawing source revisions and preserved source attachments; reject missing/cyclic references. This is a validated versioned foundation, not the complete E1/E4/E5 feature schema.

Explicitly convert legacy format0 in memory and save with an untouched original-byte backup. Journal base/next documents with hashes before atomic primary replacement; test actual process termination at prepared/replaced boundaries, interrupted/corrupt recovery, acknowledged/unknown commit reconciliation and explicit recovery with corrupt-byte preservation. Never silently repair or delete Platform's stale leases; full process ownership recovery remains the upstream boundary.

External references use document+definition identity, relative locator hints, Latest/Pinned intent and embedded verified effective snapshots. Refresh is read-only and preserves last-good content on missing/replaced/incompatible/ambiguous sources. Latest produces an explicit candidate, never automatically updates historical state; full product-wide publication/auto-follow remains E4.M4. Reject dependency cycles and incompatible runtime provenance. No global multi-document atomicity claim: source publication and consumer adoption are separately staged.

Verify copied/moved documents, two instances sharing a definition, immutable closure, restore-as-new-revision, independent drawing revision binding, source fidelity, stale/cancelled writes, symlinks/hardlinks, corruption/partial/crash saves and older-reader refusal. Add a source+consumer native demo and actual manual inspect/convert/verify/snapshot/restore/reference/recovery flow through shared authenticated authority. Package 0.0.4 experimental after exact Windows/Linux CI, relocated package tests and real public Platform discovery/install/demo/open/save/reopen verification.
