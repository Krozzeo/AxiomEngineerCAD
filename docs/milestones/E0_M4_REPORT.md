## Manual review / installation

Install/activate **0.0.4 experimental**, then Load Demos. Open **E0.M4 Native Version Lab**. Edit Notes → Apply properties; Validate current content → Create immutable version → Save document. Select a prior version → Restore as new revision → Save. Open Source Plate to edit/build/keep geometry, validate/version/publish/save, then Check source updates in the consumer → Validate candidate → Adopt validated candidate → Save. An ordinary legacy project can be explicitly converted; saving retains its original bytes. Recovery controls appear only when a verified journal needs reconciliation.

Publication requires exact PR CI, relocated ZIP lifecycle/source hashes/both corpora/native conversion-validation-version-save-reopen, and actual public Platform discovery/download/hash/install/activation/demo/launch verification. Final public outcomes belong to the exact release/PR evidence; local checks do not substitute for them.

Bounds and omissions: strict versioned storage of shipped probe types; no broad feature/expression/drawing renderer, arbitrary surface-mate propagation, automatic assembly Latest following, interference, multi-document atomic commit, history garbage collection, universal power-loss guarantee or WebGPU acceptance. Native graph/entity fields are validated storage foundations, not claims of their future mature editors. E4.M4 implements full publication/update behavior; E0.M5 is next after owner review/progression. Do not silently expand schema or remove historical data.
