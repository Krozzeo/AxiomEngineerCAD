# E1.M5 — Exact sketch extrusion and owner workbench changes

State: in progress, owner request 2026-11-02. Base: delivered 0.1.5 / 8bb1cc7672c1434c7fd430aa37eb991653a1802d (PR13). Target: 0.1.6 experimental. Accepted Platform SDK pin unchanged unless inspection proves otherwise; Platform main checked at 6d240845cd77eb1879738d32c9f2b8fcfd7297c5.

## Scope and acceptance

1. Exact CPU/OCCT extrusion of actual closed line/full-circle sketch profiles, one outer region with bounded contained holes, canonical/proven planar support, positive or reversed depth, additive history/dependencies and real volume/area/bounds queries. Reject open/branched/self-intersecting/ambiguous profiles and invalid/disconnected additive booleans atomically. Parameter/sketch edits regenerate the solid and proved semantic references. No mesh-only success or general feature breadth claim.
2. Fix CSP-constrained drag using the unchanged pinned solver: same typed authoritative preview fallback where browser bindings cannot run; constrained motion follows available freedom instead of imposing impossible coordinate targets. Preserve all source constraints, stale/cancel guards and temporary-target release. Test free/fixed/partially-defined endpoint, midpoint, center and whole-line motion, including the actual CSP failure.
3. Direct visible-sketch hover/pick/double-click edit in Model; generous semantic child-point hit tests independent of marker visibility. Hidden/edit icons in Features, diagonal pencil, Sketch Manager menu wording and three command-ribbon sizes. Remove Model's four preset buttons; F6 isometric, F7 trimetric, retain F8 and orbit/pan/cursor zoom.
4. Continuous Smart/Horizontal/Vertical/Aligned/point-distance/radius/diameter dimension tools: pick one/two semantic participants after entering the tool, measured editable value, placement-sensitive Smart inference, click/Enter commit, remain active, Esc clears draft then exits. Atomic overdimension rejection, including radius/diameter aliases and rank-dependent driving dimensions; intentional reference dimensions stay available.
5. Selection-first compact Inspector: editable entity/dimension names, reference-specific constraints, only common relationships for multi-selection, persistent entity context when selecting a relation, scrollable lists, target hover/selection, auto-commit coordinate edits, correct Reference state and constructive parent-only checkbox. Remove global/support/help/Update/Delete controls requested by owner. Target changes stage safely and auto-apply only once a complete valid replacement exists; Esc cancels an incomplete target edit.
6. Parameter Manager: spreadsheet-style parameter, equation-binding and feature-ordered model-dimension tables. Inline name/unit/expression/optional Description; empty insertion row for parameters/bindings, Enter/outside-row commit, Esc cancel, autocomplete and deletion. Stable-ID-aware transactional rename rewrites consumers safely. Values/edits use the same shared tools and geometry verification; bound/reference values cannot contradict their drivers.
7. Coordinate view updates/source navigation across main, native detached and authenticated hosted panel frontends. Reuse the existing Model owner for Go to source; never transform a Parameter-only frontend into a second Model view. Refresh working geometry after parameter edits while respecting retained read-only source selection.

## Data and contracts

Use explicit new E1.M5 sketch/parameter/extrusion profiles for editable metadata and new feature semantics; never rewrite immutable old versions. Names/descriptions are bounded literal text, not instructions/expressions. Keep native format1, stable references, pinned exact kernel/solver, one human/agent reducer, review gates and local-only exposure. Old 0.1.5 decoder must refuse new profiles without writing.
