## Manual review

1. Install/activate the published 0.1.7 candidate and Load Demos → **E1.M5 Extrusion & Sketch Workbench**. Existing user projects remain untouched.
2. Edit Plate profile. Downstream extrusion is rolled back. Add lines/circles/rectangles, even open/crossing/disjoint temporary contours. Inputs must remain usable. Exit must rebuild only a valid enabled chain; invalid finish keeps editing active. Undo or repair, then Exit again. Disable the consuming extrusion if deliberately retaining an unfinished profile.
3. Draw a line and make its midpoint coincident with a fully constrained line's midpoint. Drag an endpoint: length and angle can change while the midpoint relation remains satisfied. Inspect DOF and source constraints.
4. Dimension mode retains orange preselection. A measured value is focused/selected for direct typing. Right-click/Escape backs out one selected reference at a time, then exits. Existing dimensions can still be edited and dragged. A redundant/conflicting driving dimension offers Keep driving, Reference or Cancel; Escape cancels the dialog. Kept conflicts remain diagnosed and must be repaired before rebuilding consumed geometry.
5. Use Disable/Enable in Feature Manager. Dependencies are effectively suppressed without destroying source; explicit child disables remain. Delete the bound extrusion: owned equation bindings disappear, parameters remain, hidden references stay hidden.
6. Parameter Manager: create a value `5` with Automatic unit. It begins scalar; bind it to length and it becomes mm. Scalar-to-angle binding means degrees, stored canonically in radians. Incompatible simultaneous targets fail without changing source. Complete `StockDepth + StockW`: only the last token changes. Creating an unrelated parameter must not require solving unrelated conflicting sketches.
7. New Sketch: start with a selected plane/available proven face, start without support then choose one, or use Model face context → New Sketch. Choose normal/right orientation, create and verify horizontal sketch coordinates follow the chosen screen right. F8 and camera transitions stay gradual.
8. Edit Plate extrusion. Bound depth is gray/read-only; Go to source highlights its expression row. Reverse is a pressed-state icon button. Toggle exact Preview without changing source; Apply commits and Cancel restores working geometry. The Model panel is activated for operation editing.
9. Save, close and reopen: orientation, dimensions, inferred units, source bindings, explicit suppression and visibility persist. Earlier immutable versions remain unchanged.
