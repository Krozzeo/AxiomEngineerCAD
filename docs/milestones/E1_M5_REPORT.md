# E1.M5 — Exact extrusion and semantic workbench

Review candidate, 2026-11-02. Version target0.1.6, stacked on delivered0.1.5/8bb1cc7672c1434c7fd430aa37eb991653a1802d. This report is not publication or owner acceptance. Platform SDK/kernel/solver pins remain unchanged.

## Implemented and locally exercised

- Closed profile extraction from actual source lines and full circles: one region, up to four strict holes; independent polygon/circle area, perimeter and centroid. Real OCCT extrusion on the sketch plane, reversed depth and additive solid history. OCCT B-Rep validity/one-solid postconditions and analytic volume/area oracles. Open, branched, crossing, touching, disjoint and nested-island contours fail without modifying the input. Exact headless measurement and Model tessellation use the same source. Native validation and immutable verification include the extrusion graph.
- Parameter/sketch edits regenerate the exact extrusion. Depth is available in the binding and model-dimension tables. Unique exact cap faces support subsequent sketches. Unsupported display faces/edges are explicitly transient and cannot become saved sketch supports. The current bounded feature supports one connected primary part, up to eight additive extrusion operations, depths0.001–10000mm and at most64 sketch primitives. Retained probe studies keep their original contract; creating a sketch-based extrusion starts in a new part/current M5 demo. General multi-body modeling and drawing authoring remain later milestones.
- M5 source profiles add bounded literal entity/semantic child/dimension names and parameter descriptions. No immutable M2/M3/M4 content is rewritten. Named driving dimensions may be referenced using `dim.Name`; stable source dependencies, units, ambiguity and cycles are checked. Measured reference dimensions are not expression drivers. Parameter and named-dimension rename rewrites parser-resolved references only, preserving unit suffixes/functions and document/local scope.
- Source-preserving constrained drag projects cursor intent into available freedom and re-solves with the unchanged pinned PlaneGCS. Browser bindings that require forbidden string evaluation use the same typed authoritative preview worker. No `unsafe-eval`, source constraint deletion or permanently stored pointer targets. Actual mouse test: a one-DOF guide with redundant horizontal relationships moves vertically while blocked horizontal cursor displacement is ignored; its relations/history/one-DOF status remain unchanged.
- Visible sketches can be hovered/picked/double-clicked in Model. Child point CPU hit testing covers hidden center/endpoint/midpoint markers. Hidden/editing indicators, diagonal pencil, requested Sketch Manager action names and small/medium/large ribbon commands. F6 isometric/F7 trimetric, F8 normal, existing camera interaction retained. Model's four preset overlay buttons removed.
- Continuous Smart, horizontal, vertical, point/line distance, angle, diameter and radius commands. Enter/click commits, button becomes Exit and stays active between dimensions. Smart uses placement to choose horizontal/vertical/aligned intent. A second/redundant driving dimension is refused before persistence using identity/alias checks and independent constraint rank. Reference state remains explicit.
- Selection-specific compact Inspector: editable title, reference DOF, scrollable contextual constraint list that persists when selecting one of its relations, common-only multi-selection relations, automatic numeric commit, parent-only Constructive and selected-dimension-only Reference. Targets stage safely and apply only as a complete validated set; Escape cancels. Hover/selection identifies the actual affected semantic role.
- Three inline Parameter Manager tables: parameters (optional Description), equation bindings, existing feature-ordered model dimensions. Enter/outside-row commit, Escape discards the draft, bounded context autocomplete, atomic binding replacement, editable unbound driving values and explicit bound/reference fields. Main/native/hosted panel navigation selects one existing Model owner. Parameter-only hosted frontends do not synchronize/render their own Model sketch. Historical read-only source selection is respected.

## Owner test flow after publication

1. Install the current experimental0.1.6 from Axiom Platform and Load Demos. Only **E1.M5 Extrusion & Sketch Workbench** is advertised; older user projects remain untouched.
2. The plate is an exact extrusion of its four-line outline and circle. Open its sketch from Features or double-click visible geometry. The construction guide below the plate is constrained to vertical translation; drag it and inspect its one DOF.
3. Inspect circle perimeter versus center and line versus endpoints/midpoint. Their constraints differ. Pick a relation without losing the contextual entity list. Rename it, test Reference, and use Delete/Clear/target replacement.
4. Enter a dimension command, choose compatible references, edit the measured value, place it with click/Enter, and repeat. Escape clears a draft, then exits the command. A second driving dimension must fail without changing geometry.
5. Open Parameter Manager. Change StockWidth/StockHeight/StockDepth in place; verify the working model updates. Add an equation such as `doc.StockDepth / 2` or `dim.PlateWidth / 2`; rename its source and verify dependencies remain intact. Invalid units/cycles retain the last valid model. Test Enter, outside-row commit and Escape.
6. Separate Parameter Manager and use Go to source. The existing Model view receives the selection; no new Model window/frontend is opened. Return/dock/close/reopen panels normally.
7. In a new sketch, create a closed rectangle on Front or a proven cap, exit, select it, and choose Features → Extrude. Edit depth/reverse; test a deliberately open profile and disconnected addition. Failure must preserve the previous working solid.

Owner geometric/manufacturing approval and milestone acceptance remain separate from software installation/validation.
