## What changed

- Dimension Inspector Value is a single-row, single-column table. The cell searches compatible parameters or accepts a literal directly. Newly placed dimensions focus/select it; successful Enter updates restore focus/selection. Existing dimensions use this same Inspector editor. The placement draft retains its temporary Model editor until committed. Diameter labels restore `Ø `.
- Straight-line Snap infers horizontal/vertical within five degrees and commits the corresponding relation atomically. Ctrl bypasses inference. Holding Shift on the second click starts the next line at the previous endpoint with a coincident relation, in the next creation transaction. Escape discards only the unfinished segment. Geometry tools show a crosshair.
- Equation bindings and Geometric constraints table cells have no grid boxes. Sketch editing updates the Exit Sketch ribbon as soon as the edit session begins, before rebuild/diagnostics finish.
- Orbit increments operate about the current screen frame, without a world-up inclination clamp. Middle drag rotates; Ctrl/Shift middle drag pans; Alt middle drag rolls. F8/double middle still smoothly returns to the active sketch support, including its Right rotation. Wheel zoom remains pointer-centered. Based on [SolidWorks mouse controls](https://help.solidworks.com/2021/english/SolidWorks/sldworks/r_Middle_Mouse_Button.htm?id=5.8.1.17), with the existing Shift-pan shortcut retained.
- Extrusion preview uses translucent green geometry. Depth updates preview on Enter/blur, not each character. Only Apply commits. Escape/right-click cancel. Preview remains non-authoritative and cannot be used as saved source or exported drawing.
- Engineer's lifetime 256 adapter/proof receipt and 10,000 CAD receipt quotas and 32-export audit quota are removed. Exact replay and changed-input rejection remain. Limits on malformed input, geometry capability, concurrent work, revisions and explicit review authority remain validation, not an operation allowance. Platform's separate Hub lifecycle is not changed by an Engineer installation.

## External references

While editing a sketch, use Sketch → External reference and pick a vertex/edge/planar face in Model, or Origin/axis/plane in Manager. Selection filters are under View. The imported source-controlled construction geometry appears in the sketch tree and can be used by the usual dimension/relation tools and Targets.

References retain producer, definition, semantic role and occurrence path. The primary part is supported; component occurrence editing remains later scope. Straight edges project as lines; complete supported circles project as circles only if the projection remains circular. Collapsed lines/axes project as points. Intersecting planes/faces provide a plane trace; parallel planes/faces provide their explicitly named center projection. Curved faces, ellipses/arcs and unproven transient/ambiguous roles fail explicitly. This does not claim full face boundary conversion.

Exact OCCT endpoints/linear edges carry conservative geometric witnesses. A new coordinate/edge witness means a changed reference; no array index or triangle identity is accepted. Native verification independently regenerates upstream geometry and checks the projected coordinates plus source-controlled constraints. Source changes that invalidate a witness stop with LostReference; delete/reselect the construction reference before rebuilding. This is conservative repair, not general persistent topological naming. Dependencies prevent source deletion/cycles. Old strict readers refuse the new entity metadata rather than silently dropping it.

## Owner demo

Install/activate 0.1.9, then load **E1.M5 Extrusion & Sketch Workbench**. Existing projects and older installations remain intact.

1. Select Front → New Sketch. Set Right to 90° and create. Draw a near-horizontal line; hold Shift on its endpoint click, then finish the next segment near vertical. Inspect Horizontal, Vertical and Coincident relations. Escape cancels the next unfinished segment.
2. Place a line dimension. Its Inspector cell should already be selected. Type a number, Enter, then type another number immediately. Search a compatible parameter in the same cell. No second persisted-dimension value editor should appear. Check circle labels use `Ø`.
3. External reference → select Origin or an axis from Manager. For model vertices/edges/faces, first choose the View selection filter. Use the imported construction points/lines in a dimension or relation to local geometry. Save/reopen and inspect the source identity. Curved/unproven geometry must produce an explicit refusal.
4. Rotate with the middle button through the old upper/lower limits. Repeat after a 90° Right sketch orientation. F8 returns smoothly to the correct sketch frame.
5. Create a closed rectangle sketch overlapping the plate and choose Extrude. Change Depth, press Enter or blur: preview changes in translucent green and the working revision stays unchanged. Try Escape and right-click. Reopen and click Apply explicitly to commit. The demo's original plate depth is parameter-bound; edit StockDepth or test a new extrusion for an unbound Depth field.
6. In Parameter Manager, inspect Equation bindings and Geometric constraints without cell boxes. Repeat sketch/layout/visibility/save interactions freely; the previous cumulative Engineer operation limits should not return.
