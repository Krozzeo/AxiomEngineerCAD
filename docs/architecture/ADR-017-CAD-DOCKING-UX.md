# ADR017 — CAD docking and cursor navigation (0.1.1)

2026-10-31. Owner requested a SolidWorks-inspired composition and the actual Axiom Game Engine dock interaction/aesthetics. This is an E1.M1 usability revision, not E1.M2 or a foundational CAD/MVP change. Native schema0/1, exact CPU authority, stable IDs and human-only Apply remain unchanged.

Adapt the maintained Game Engine editor dock-layout.mjs, panel-layout.mjs, styles.css and SVG icons from [fc2613243f0e52623dc053de5d9bd0796e4e7024](https://github.com/Krozzeo/AxiomGameEngine/tree/fc2613243f0e52623dc053de5d9bd0796e4e7024/apps/editor). MIT license retained in legal/AXIOM_GAME_ENGINE_UI_LICENSE.txt. No Engine domain or scene model is imported. Engineer owns its exact model and renderer.

Five slots (left/right/top/bottom/center), draggable/reorderable tabs, keyboard/pointer resize, position chooser, context menu, close, Panels reopen/reset and Separate window reuse the Engine pattern. Actual existing nodes and their listeners move into a same-origin child document; a shared document lookup proxy keeps the original controllers alive. A standalone editor retains one renderer with its moved canvas. There is always one authoritative CAD adapter session/lease. Closing or returning a child reattaches its live node. Popup blocking leaves its panel intact. Parent closure returns children; no secondary document is silently saved. Separate Model can coexist with Drawing in the main window.

Platform embeds a product-origin iframe under a different-origin COOP-isolated shell. Chromium deliberately severs WindowProxy access for its popup; an about:blank window cannot support DOM adoption there. In that case open a panel-only authenticated frontend of the SAME adapter/session, preserving COOP/COEP/origin/authentication rather than weakening headers or creating another project lease. A random same-origin BroadcastChannel synchronizes validated camera state and semantic selection with source-anchor matching and ordered stamps. A model window owns its display-only GPU device; exact CPU work/transactions remain in the original adapter. The child reuses a current source/revision/options-matching verified proof instead of starting a competing preview; source changes use the normal guarded build; stale selections never bind to another anchor. The child stays inert until initial source/state synchronization, does not load/save parent layout preferences, and returns the parent panel on close. Concurrent document edits retain the existing revision and pending-buffer guards. Actual Platform iframe Inspector selection, Model camera and native-close/return flows are included in browser/hardware/public-install acceptance.

Per-project presentation preferences live in bounded, identity-checked .engineer-ui.json: positions, closed IDs, order, active tabs and sizes. No window handles, credentials, URLs, model content or pixel IDs are persisted; popups never automatically reopen. Native document revision/bytes remain unchanged by layout. Human-authenticated same-origin routes serialize writes through the existing adapter queue, check a separate expectedLayoutRevision and retain stale-write conflicts. Unknown fields/IDs, oversized/corrupt/foreign/nonordinary/multiply linked files are refused and preserved. Layout conflicts require reload; corrupt preferences are preserved for inspection rather than silently erased.

The logo and File/Edit/View/Tools/Panels occupy one header row. A compact icon ribbon and gray model view follow the owner's visual reference; dark Axiom dock chrome/icons follow Game Engine. All outer layout uses bounded flex/grid with no document scroll, and panel bodies scroll independently. Header/menu/status remain reachable when every content panel is closed. Diagnostics retains the earlier labs. No future sketch command buttons are fabricated.

Horizontal rightward mouse orbit now decreases yaw (and keyboard arrows match). Wheel zoom finds the nearest ray/triangle display surface only as a camera anchor; absent a hit it uses the cursor's view-center plane. Orthographic and perspective projections adjust pan to preserve that world anchor under the cursor. This is presentation navigation, never a semantic reference or mesh-based CAD measurement. Minimum zoom is bounded and clamps preserve the same anchor. Keyboard +/- remains center zoom.

Evidence: eight added camera/persistence/security cases (123 total), actual real-GPU same-node separate-window navigation/selection, blocked-popup recovery, five docks, tab drag, keyboard resize, close/reopen, reload and unchanged native bytes; three browser sizes. Exact final CI/public artifact and fresh Platform installation evidence are recorded in the delivery, independently of source-local checks. E1.M1 owner acceptance remains pending.
