# ADR-023 — Exact extrusion, semantic sketch interaction and coordinated parameter tables

Date: 2026-11-02. State: implementation under the owner's explicit E1.M5 + attached workbench request. No change to accepted kernel/solver/SDK pins or approved MVP. See E1_M5_PLAN.md for the delivery/acceptance map.

Use explicit E1.M5 source profiles for extrusion and editable sketch/parameter metadata. Preserve immutable versions and the E1.M2/M3/M4 decoders. New names/descriptions are bounded literal metadata; stable IDs remain the references. Transactional parameter rename rewrites only consumers of the renamed stable identity using the expression parser's actual reference resolution. No JavaScript eval.

Closed-profile extrusion starts with one outer closed region and bounded strictly contained holes, using existing lines/full circles and actual OCCT B-Rep. Independent profile area/perimeter/centroid plus exact validity/volume/area/bounds evidence precede commit. Additive booleans must yield one valid connected solid. Ambiguous/open/self-intersecting/nested-island regions fail explicitly; multibody and broader feature breadth retain their scheduled E3 gates. Persisted selectors use proven producing roles; uncertain split/merged faces are not silently named as stable references.

Dragging uses the same pinned PlaneGCS engine and independent Jacobian/residual checks. Browser binding paths that require Emscripten dynamic JS are not allowed to weaken CSP: use the existing typed, revision-checked local sketch.preview tool in the bounded warm Node worker instead. Source constraints remain authoritative. M5 pointer targets follow available constrained motion with explicit temporary target release, rather than forcing both coordinates of every endpoint. Numerical projection is a proposal/initial guess only; exact solver validation and independent residual/DOF checks remain necessary before any commit.

Dimension creation is a continuous explicit tool mode with semantic point/entity picking. Smart inference selects a typed dimension, never invents a value. New driving dimensions that add no independent restriction are refused, including radius/diameter aliases; references remain an explicit measured alternative. Old historical constraint evidence is not rewritten. Sketch Inspector relation selection retains its inspection context, while role-specific participants and multi-selection intersection prevent unrelated relations from appearing.

Parameter and binding rows use one revision-captured atomic edit on Enter or leaving the row; Esc cancels the draft. Targets are stable identities despite human-readable names/autocomplete. Model dimensions edit through the same bounded commands; reference/bound values cannot bypass their source rule. Local view coordination refreshes working geometry and routes Go to source to the existing Model owner across main/native/hosted panels. Messages only request UI navigation/refresh; they grant no domain authority, new lease or file access.

Acceptance: native old-reader refusal and immutable-history preservation; exact profile/B-Rep and solver oracles; stale/cancel/invalid/overdimension rollback; same human/agent commands and full reviewed Apply; actual continuous dimension/Inspector/table/Separate Windows workflows, physical GPU/performance and retained PDF/security/lifecycle cases. Final exact-head CI and fresh public installation are required. Publication is for owner review, not automatic acceptance or main/stable merge.

Named driving dimension expressions use `dim.Name` only when the explicit M5 profile retains their stable `(sketchId,constraintId)` dependencies. A bound dimension resolves through its owning parameter, so direct/indirect cycles are refused. Reference dimensions do not become hidden feedback drivers. Rename rewrites only parser-resolved symbols; replacing an alias with a different source identity is refused.

Initial extrusion caps use explicit producer planes checked against actual unique B-Rep faces. Additive cap identity advances through OCCT Modified/IsDeleted/IsSame lineage; split descendants are ambiguous and deleted descendants are lost. Display-only faces/edges carry `TransientDisplayOnly`, never a fabricated stable role. Volume, area and prism centroid use independent profile oracles; exact volume/surface centroids are queried from GProp.
