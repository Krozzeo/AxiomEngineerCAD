# ADR018 — Selection, reference navigation and operation workbench (0.1.2)

2026-10-31. Owner supplied the detailed interaction/organization change list and reference colors/icons. This remains E1.M1 usability work, not a sketch/assembly editor milestone. Native0/1 schemas, immutable versions, exact CPU authority, semantic scopes and human Apply/Save guards are retained.

Auto is the default selection filter: proven B-Rep corner vertices, exact edge roles and face roles share the current depth-tested GPU ID attachment; readback prioritizes visible Vertex, then Edge, then Face within the existing bounded picking radius. Explicit body/feature/component/datum filters remain. Hover reads the display ID attachment only and never submits a domain operation/receipt. Pointer coalescing, source invalidation and filter changes prevent obsolete preselection. Semantic clicks still resolve through the authenticated current manifest. Display overlays draw orange #FF8000 boundaries and selected blue #00AEFF, wider screen-space edges and filled vertex circles. Face boundary segments derive from the displayed face triangulation only for highlighting; they are never promoted to CAD topology or measurements. GPU fills use the exact selected manifest ID. The existing supported producer/occurrence limits remain.

Origin is an additional canonical ReadOnly point datum at definition-local [0,0,0], stable ID datum-origin. It adds no persisted feature or native migration. Canonical reference frames now contain7 entries. Existing plane IDs/roles remain xy/xz/yz; owner-facing names are Front/Top/Right respectively. View buttons follow those same frame normals. The accepted E0 vector drawing template retains its established top/front/right projection definitions; these UI labels do not silently change a drawing. Selecting/hovering reference frames displays only those references without checking global Reference planes & axes. Source hover traces currently displayed feature ancestry; unsupported geometry is not invented.

The corner triad projects world axes into the current camera basis. Axis activation aligns to its direction; repeating an aligned axis reverses it. Orientations interpolate shortest yaw/pitch over320ms; principal views, normal-to, triad and keyboard orientation use that path. Pointer orbit remains continuous and cancels a pending transition. F8/double-middle click aligns normal to a selected plane/planar face, otherwise the nearest principal camera direction. Camera/layout/selection do not mutate native content. The triad/reference feedback also updates on unsupported GPU paths, separately labeled from physical GPU evidence.

Manager replaces Feature History; Features/Components/Mates retain actual source identities. Icons, framed tab contents and a pinned format/revision/session footer separate model content from document status. Inspector contains current selection properties, with Reference details and Source and revision under a collapsed Details section. The old entity query control moves to Diagnostics, outside Inspector. Document properties is a new dockable central panel, closed by default, with General/Revisions navigation and the existing guarded Name/Notes editing form. File → Document properties and Panels open/focus that same panel. Old layout preferences preserve their positions and keep the newly introduced panel closed. No domain property editor is bypassed.

The operation bar exposes Assembly/Features/Sketch/View/Analysis/Drawing/Diagnostics tabs. Actual current commands move to their applicable tabs; unimplemented editing tabs state their availability rather than exposing fake tools. Single-menu/outside-dismiss behavior includes Panels. Save and quick-save share the existing command; pending or unsaved state adds a highlighted asterisk and bold Save*. The CAD favicon is an original SVG of the existing mark. Model's bottom strip presents actual model/document/task messages and detected viewport errors.

Production Load Demos advertises and generates only the current workbench demo. Previous user projects/demos are preserved. Historical numerical/native/review regression inputs are explicitly generated by the acceptance harness using an injected trusted constructor catalog and registered through normal Platform lifecycle; they are not published demo choices. The normal adapter defaults strictly to its manifest catalog. No environment or HTTP switch enables archived production demos.

Acceptance:125 domain/security tests, including canonical Origin/no-native-write and current-only production demo rejection; actual human operation-tab/panel navigation, semantic depth-tested Auto priority, hover with zero domain requests, colors/markers, reference visibility independence, operation hover, menu dismissal, saved/draft UI state, intermediate camera state and axis inversion, keyboard/double-middle alignment, native-byte preservation, retained numerical/review/PDF flows and public Platform installation. Physical NVIDIA evidence is distinct from unsupported CI paths. Exact final CI/public artifact provenance belongs to the delivery PR and external manifest.
