# Owner-requested workspace restructuring

Proximos cambios:
* Encontré un bug, cuando abro la pestaña Components de Manager, y luego quiero volver a abrir la pestaña features, el contenido de la pestaña no cambia y queda clavado en Components. PAra volver a features actualmente tengo que abrir la pestaña Mates (esta si la abre correctamente) y luego pasar a Features.
* En Features, en la primera linea del contenido, debe aparecer el nombre de la pieza / ensamblaje que se esté trabajando, ya sea con la pieza maestra o si se ingresa dentro de otra pieza
* Vamos a crear distintos tipos de visualización de componentes que se agregan a un ensamble. El visibilidad por defecto es Model: Las geometrías de referencia (sketchs, planos, ejes, sistemas de coordenadas, etc) no son visibles, solamente el modelado. Otra visibilidad es Entire Part, esta trae todas las geometrías de referencia (sketchs, planos, ejes, sistemas de coordenadas, etc) además del modelado. Otra visibilidad es Hide/Reveal, que oculta o desoculta la pieza. Se puede seleccionar la visibilidad con el menú del click derecho sobre el componente tanto en la vista de Model como en el Component Manager. 
* Al entrar en modo edición de un componente, los demás componentes del ensamble deben ponerse transparentes. Tambien agrega una barra superior en Model, igual a la que sale cuando estás en modo edición de sketch (que dice, por ejemplo: Base profile Front (XY) - Fit sketch - Normal to - Exit Sketch) que diga el nombre de la pieza que se está editando y tenga un boton de atajo rapido de 'Exit edit'. Reusa el mismo código y solo adapta lo necesario.
* Al entrar en modo edición de un componente, la operación Exit component de la barra de operaciones -> assembly debe quedar resaltada, quitale la aclaración del nombrede la pieza en el nombre de la operación de la barra
* Vamos a hacer un cambio estructural en el proyecto, como dijimos, un proyecto puede contener varias piezas y/o conjuntos. Todo lo que estuvimos trabajando hasta el final de la E3 corresponde unicamente a la creación de una pieza. Lo que quiero que hagamos ahora es que creemos un panel más, 'Project' que va a operar como un manager de archivos del proyecto. Ve el Panel Project del proyecto Axiom Game Engine y copialo, reutiliza su código tal cual y solo adapta lo que necesites para que funciones en nuestra app y con la funcionalidad que queremos darle. En principio, quiero que desde allí puedas ver todas las piezas que tiene el proyecto, con su nombre y una imagen preview de la pieza/conjunto centrado en vista isométrica. Con doble click se abre esa pieza y se trabaja igual que veniamos trabajando. Con click derecho sobre una pieza desde Project se abre un menú donde tienes las opciones 'Open' para abrirla, 'Delete' para borrarlo, con confirmación, y 'Show in explorer' para abrir la carpeta donde se encuentra este archivo y 'Close' para cerrarlo si está abiero (si está abierto tambien debería haber un icono de una X en la esquina superior derecha de la imagen preview para cerrarla). Clikear y arrasterar a la vista de Model o el component manager coloca una instancia de esa part/conjunto en la parte actual (no se permiten recursivos). Click derecho en ningun archivo de Project te da las opciones de 'Create Folder', 'Create Part/Assembly' y 'Show in explorer' para abrir el directorio actual. Puedes crear directorios y navegar por ellos igual que en Axiom Game Engine. Si seleccionas una parte o conjunto de project, y existen instancias de esa parte/conjunto en el conjunto abierto, estas resaltan. Agrega tambien una barra de pestañas entre la barra superior de menus y la barra de operaciones, en esta barra aparecerán las pestañas de todas las piezas que se tienen abierta, con su nombre a la izquierda y un icono de una X a la derecha para cerrarlas. Cliquearlas establece el area de trabajo para esa pieza/conjunto.
* Con este nuevo sistema, al crear un nuevo proyecto, no arranca listo para modelar como venia, sino que arranca 'vacio' y debes crear una parte/conjunto desde project para arrancar a trabajar en una pieza.
* El nombre del proyecto que figura en la barra superior ahora debe ser '[Nombre del proyecto] • [Nombre de la parte actual]'
* Cambiamos el nombre de los grupos de 'Assembly group' por solamente 'Group'
* Debes poder clickear y arrastrar componentes y grupos del component manager para reorganizarlos (entre medio de otros componentes), ponerlos dentro de grupos o sacarlos
* Agrega menu Create en la barra superior, en el habra las opciones: 'New folder' que crea una carpeta en la ruta actual que se encuentra project (abrirlo si esta cerrado, ponerlo en foco si esta abierto), 'New part/asembly' que crea una pieza/conjunto en la ruta actual que se encuentra project (abrirlo si esta cerrado, ponerlo en foco si esta abierto), 'New version' que crea una nueva versión de la parte/conjunto trabajado (abre o pone en foco el panel Versions)
* Agrega panel Version con create new version e historial de versiones tipo tree view, con ramas y main tipo github, en left, en el puedes acceder a las versiones pasadas haciendo doble click, fusionar una rama al main, crear una rama nueva, borrar versiones/ramas, etc. Puedes seleccionar elementos del tree view y apretar supr para borrarlos, click derecho sobre un elemento para el menú con las opciones 'Open', 'Create new version', 'Create new branch', 'Make main branch', 'Delete', etc.
* Insert / manage component vamos a dividirla en varias operaciones. Por lado vamos a tener la operación Insert, Insert solamente inserta componentes. Debe haber una lista tipo tabla de partes para seleccionar (las partes que esten abiertas en el proyecto unicamente), y el botón de insert instance, de momento solamente eso, quita todo lo demás. Por otro lado tendremos a la operación Move component, esta al abrirla, la primer tabla de selección es para seleccionar la o las partes/conjuntos (se pueden selecionar cliqueando desde la vista de model o desde el component manager) luego hay dos modos de movimiento: Translate y Rotate (se selecciona con botones con íconos como en otras operaciones) y cada modo tiene a su vez dos submodos: Absolute y Relative (se selecciona con botones con íconos como en otras operaciones), el primero utiliza coordenas absolutas y el segundo coordenadas relativas a la posición de la pieza. Segun el modo y submodo que elijas, ingresas el o los valores en el campo de input y al dar enter o apply se aplica el movimiento mientras las constrains del conjunto lo permitan. La operación no se cierra al dar apply, se puede dar apply o enter multiples veces si se desea. Tambien, deberías poder mover piezas sin constrains cliqueando y arrastrandolas con el mouse, igual que en solid works. Crea tambien un botón large en la barra de operaciones -> Assembly que cumpla la funcion similar a Cancel Feature de Feature, que cancela las operaciones que se estén trabajando en ese momento, y ubicalo a la derecha de todo, igual que en Feature.
