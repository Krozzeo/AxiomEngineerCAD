# E4.M5 owner-authorized changes

Proximos cambios:
* Cada vez que guardo pierdo la capacidad de sleccionar cosas en Model, me sale 'Model changed. Drawing and selection are stale; rebuild to continue.'. Realiza este rebuild automaticamente luego de guardar o cuando sea necesario hacerlo.
* Cuando intento guarda la demo sale 'InvalidInput: Datum directions must be unit vectors.' averigua porque sale este mensaje de error y si hay que corregir algo
* En el Manager, cuando haces click derecho sobre una constrain (ya sea en Components o en Mates) agrega la opción en el menú del click derecho 'Disable'/'Enable'. Las constrains marcadas como Disable no se computan, es como si no estuvieran, y desde el manager se ven con el texto en gris y el ícono de pausa (el mismo que usasate para Disable el menu del click derecho del Feature Manager) a la derecha, esto aplica tanto para constrain en Component como en Mates
* Si por algun motivo una constrain se rompe o queda en conflicto, cambia la fuente de esa constrain en el Manager a rojo, negrita y agrega un ícono rojo con una 'X' a la derecha para marcar que está en conflicto, esto aplica tanto para constrain en Component como en Mates
* Si por algun motivo una constrain pierde una o más referencias, cambia la fuente de esa constrain en el Manager a verde, negrita y agrega un ícono rojo con una '?' a la derecha para marcar que la Reference Missing, esto aplica tanto para constrain en Component como en Mates
* Si una parte no posee ninguna constrain, entonces la pestaña Mates del Manager permanace deshabilitada y se habilita solamente cuando la parte tenga al menos un constrain

Respecto al versionado, vamos a hacer unos cuantos cambios estructurales y simplificaciones.
* Quitamos la mecánica de branches (quita la opción en el menú del click derecho del Versions) dejamos unicamente un sistema de versionado simple, donde hay una unica rama principal de versiones ordenadas y una versión Main que es la versión principal y de trabajo
* La estética de tree view de las versiones está horrible. Rehazla de cero, que tenga una estética simila al tree view del Manager, con la preselección y selección activa. Quítale el texto 'Working branch: main · Main: main', la versión activa debe quedar resaltada visualmente. Agrega íconos en la tabla de versiones a la izquierda de cada versión (usa la 1ra imagen adjunta para crear el ícono estandar, y luego crea otra version de ese mismo ícono, usando el icono de fondo pero agregando un check mark delante para la versión abierta). A la versión Main, agregale un ícono a la derecha para discriminarlo (usa la 2da imagen adjunta de referencia para crearlo)
* Nos dehacemos de las publicaciones, usaremos directamente todas las versiones existentes de la parte
* Cambia el boton 'Create new version' por un botón con un ícono de '+', además, si estás abrís una versión que no es la Main, deberías tener dos botones más, uno con el ícono de Main (que vuelve a la versión abierta la versión Main -y por consecuente, la latest- y la ubica arriba de todo en el tree view) y otro botón con un ícono de exit para salir de esa versión y volver a la Main. Deja el botón de refresh. Todos deben ser botones con íconos ubicados en la misma linea, del mismo tamaño, ubicados en la parte superior del panel como están actualmente.
* Al seleccionar una versión de la tree view, en el inspecto debería mostrar lo siguiente: Name (campo editable), Description (campo editable), información sobre el uso de esta versión en otros conjuntos del projecto si hubiera, botones Open (O Close, si está abierto y si no es el main), Make Main (si no es el mail) y Delete
* Se puede eliminar versiones seleccionandolas del tree view y apretando Supr, tambien haciendo click derecho en una versión del tree view y dando a Delete.
* Quita la sección Published vertions (ya nos deshicimos de esa mecánica) y la sección Component vertions la vamos a mover a Parameter Manager, rehaz de cero la tabla de component versions para que se ajuste al tipo de tabla, estítica y organización que ya se viene utilizando en el Parameter Manager. Esta sección solo existe si la parte trabajada es un conjunto (es decir, tiene piezas agregadas) sino queda oculta. Además, vamos a hacer unos cambios a la sección Component versions: 
   - Siguiendo la mecánica del resto de tablas del Parameter Manager, la tabla de component versions debe poder seleccionar sus filas al cliquearlas, y al seleccionarlas tambien debe resaltar la pieza en la vista Model. 
   - Quita la columna Policy, vamos a gestionarlo de la siguiente manera: En la columna Versions va a figurar el desplegable para seleccionar todas las versiones existentes de la pieza, pero la primera opción será Latest, de esta forma, si está seleccionado Latest, entonces siempre traerá la ultima versión (la Main), y si se selecciona otra versión en particular, entonces es un pinned en esa versión
   - Quita la ultima columna con los botones 'Preview update' y 'Apply update'. El preview update no es necesario que se ejecute, si el cambio de versión rompe constrains del conjunto, entonces aparece un cartel diciendo que X constrain entran en conflicto y/o X constrains perdieron referencia, con dos opciones, la primera es deshabilitar las constrains de la pieza que estan causando el conflicto o perdieron referencia, la segunda es aplicar de todas maneras y luego arreglar manualmente las constrains. El Apply Update se da automaticamente al dar enter o deseleccionar la fila de la tabla editada, siguiendo la misma mecanica de las otras tablas del Parameter Manager
* Vamos a eliminar el panel Versions y vamos a mover su contenido a una nueva pestaña 'Versions' dentro del panel Manager para hacerlo más dinámico

Respecto a Insertar un componente en un conjunto, hoy tenemos tres formas, cliqueando y arrastrando desde Project, copiando y pegando un componente y con la operación Insert Component, vamos hacer algunos cambios para adaptar la mecanica de versionados:
* En la operación Insert component, la tabla actual es horrible. Agrega íconos a la derecha de cada componente de la tabla, los mismo que usaste en el COmponent Manager para partes y conjuntos (discrimina partes de conjuntos). Quita el los bordes entre cada fila, deja solamente el recuadro exterior de la tabla. El seleccionado debe pintar toda la celda de color, no solamente cambiar el color del recuadro. Si hay muchas opciones, en un punto debe volverse un scroll para que puedas navergarlo.
* En la operación Insert component, agrega una segunda sección 'Version', con otra tabla similar a la de arriba, solo que en esta tabla figuran todas las versiones de la parte seleccionada. La primera opción (y la opción seleccionada por defecto) es siempre Latest, luego vienen las versiones ordenadas de más reciente a menos reciente. Lo que selecciones aquí quedará configurado en el ensamble, como pinned de una versión elegida o latest.
* En la operación Insert component, agrega una segunda sección 'Location' que es para seleccionar la ubicación del pa pieza a insertar. Quiero dos modos, con botones con íconos, el primero 'Absolute origin' que lo crea en el origen absoluto del conjunto, no tienes que configurar nada, el segundo es Reference, el cual habilita (y se pone en foco automaticamente) una tabla de selección (la misma que en otras operaciones) que te permite seleccionar un punto, arista, cara, geometría de referencia, etc, para ubicar la instancia en el conjunto. Esto no crea constrains ni vinvula la instancia con la referencia de ninguna forma, solamente se usa la referencia para ubicar espacialmente la instancia en el conjunto.
* Al copiar y pegar una parte, esta hereda la misma configuració nde versión que tiene el padre, si esta en pinned con una versión espacifica, la copia tambien, si está en latest, la copia tambien.
* La cliquear una parte desde project y arrastrarla a la vista Model, si la parte no tiene ninguna otra versión más que el mail, entonces la parte se instancia automaticamente en Latest. Si la parte tiene otras versiones existentes además del main, entonces se abre la operación Insert component con la parte que se intentó instancear automaticamente seleccionada, permitiendo que el usuario elija que versión de la pieza quiere utilizar.
